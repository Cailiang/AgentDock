# AgentDock 0.1.48

## 中文

本版本为 AgentDock README 增加了可直接理解产品用途的运行界面截图，并同步更新中英文文档与浏览器预览中的版本信息。截图覆盖客户端管理、供应商配置、MCP 同步、用量统计和诊断中心，使用内置预览数据且不包含真实凭据。

### 新增功能

- 新增客户端全生命周期、供应商编辑器、MCP、用量统计和诊断中心五张 README 配套界面截图。
- 在英文和简体中文 README 增加运行界面一览，说明每个界面对应的核心工作流。
- 新增 `docs/readme/` 图片目录，便于 GitHub README 直接展示高分辨率界面。

### Bug 修复

- 修复英文、简体中文、日文和德文 README 仍显示旧预览版本号的问题。
- 修复浏览器预览数据和诊断示例仍引用旧版本号的问题，统一为 `0.1.48`。

## English

This release adds runtime screenshots to make AgentDock easier to understand from the GitHub README, and synchronizes the version shown by the localized documentation and browser preview. The screenshots cover client management, provider setup, MCP synchronization, usage statistics, and diagnostics. They use built-in preview data and contain no real credentials.

### New Features

- Added five README screenshots for the client lifecycle, provider editor, MCP, usage statistics, and diagnostics views.
- Added an English and Simplified Chinese product tour section describing the workflow shown in each view.
- Added the `docs/readme/` image directory so GitHub can render the high-resolution interface examples directly.

### Bug Fixes

- Fixed stale preview version numbers in the English, Simplified Chinese, Japanese, and German README files.
- Fixed the browser preview data and diagnostic example still referring to an older version, now consistently showing `0.1.48`.
